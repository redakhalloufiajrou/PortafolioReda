Soy un perfil versátil que llegó al desarrollo web desde el hardware: tras el Grado Medio en Sistemas Microinformáticos y Redes y mis prácticas como técnico informático, ahora curso Desarrollo de Aplicaciones Web. Esa base me da una visión completa de cómo funciona una aplicación, desde el equipo y la red hasta el código que se ejecuta en el servidor y en el navegador.

Me gusta resolver problemas con orden: separo responsabilidades (controladores, servicios, repositorios), documento lo que hago (Javadoc, Swagger, diagramas UML) y pruebo mi código. Mi proyecto más completo es una API REST con Spring Boot y su frontend para gestionar las citas de una barbería.

Además, varios años de atención al cliente me han enseñado a comunicarme con claridad, trabajar en equipo y mantener la calma bajo presión, algo que llevo a cada proyecto.

Proyecto final · 3er trimestre

Reda Barber Club — Cut & Shave ✂️

Aplicación full-stack para gestionar una barbería: clientes, peluqueros, servicios y citas. API REST con Spring Boot organizada por capas (controller → service → repository), base de datos H2 con datos de prueba generados con JavaFaker, documentación con Swagger y Javadoc, tests con JUnit y un frontend en JavaScript modular que consume la API con fetch. La reserva comprueba en tiempo real qué horas tiene libres cada peluquero.

  • Java 17
  • Spring Boot
  • JPA
  • H2
  • Swagger
  • JUnit
  • JavaScript
  • CSS
🎥 Vídeo de la defensa
Lenguaje de Marcas · T2

R&M Wiki — Wiki del multiverso

Sitio web multipágina tipo wiki: portada con protagonistas y antagonistas, buscador de personajes, ficha de detalle que se genera según el personaje elegido, página «Sobre nosotros» y formulario para contribuir. Maquetado con HTML semántico y CSS con nomenclatura BEM; JavaScript para favoritos con contador, mostrar/ocultar ficha y navegación al detalle.

  • HTML5
  • CSS3
  • BEM
  • JavaScript
  • DOM
Programación · T1 (recuperación)

MarSTEM — Colonia en Marte 🚀

Juego de gestión por turnos en JavaScript: mantén la moral, el oxígeno, la energía y las instalaciones de una colonia marciana. Incluye mercado con productos aleatorios que se renueva cada 5 turnos, eventos aleatorios (tormentas de polvo, frío extremo, celebraciones), desgaste de instalaciones y crecimiento de población. Para el portafolio lo he adaptado a interfaz web sin cambiar sus reglas.

  • JavaScript
  • Arrays
  • Bucles y condicionales
  • Lógica de juego
Programación · T2

STEMos en el Cine 🎬

Aplicación de consola en Java orientada a objetos para gestionar un cine: salas, películas, proyecciones y venta de butacas en una matriz de 10×20. Valida datos (géneros, duración, entradas numéricas con excepciones), evita butacas duplicadas, impide cancelar proyecciones ya terminadas y genera datos de prueba con una clase Faker propia. La demo ejecuta el mismo programa en un terminal simulado.

  • Java
  • POO
  • ArrayList
  • LocalDateTime
  • Excepciones
